# Changelog

All notable changes to Cart Relay are documented in this file.

## [Unreleased]

## [1.0.3] - 2026-08-26

### Added

- A canonical POT catalog and automated translation coverage verification.
- Complete Spanish (Spain and Colombia), French, Brazilian Portuguese, and Italian translation catalogs for PHP and JavaScript.

### Changed

- Preserved JavaScript gettext calls through production minification and added RTL-safe layout behavior.

## [1.0.2] - 2026-08-25

### Changed

- Clarified maintainer-led project governance and control of official releases.

## [1.0.1] - 2026-08-21

### Added

- Responsive tabs for the settings page.

### Changed

- Removed development-only dependency metadata from production packages.

## [1.0.0] - 2026-08-03

- Added WooCommerce cart import and export using CSV files.
- Added merge and replace modes and configurable classic-cart controls.
