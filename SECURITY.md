# Security Policy

## Supported versions

Only the latest stable Cart Relay release receives security fixes. Until the first public release, security corrections are applied to the active development branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Email `gilbertrdz.dev@gmail.com` with:

- the affected version;
- reproduction steps or a proof of concept;
- the expected security impact;
- any suggested remediation or disclosure deadline.

An acknowledgement should be sent within five business days. Valid reports will be investigated privately, corrected in a dedicated security release, and disclosed after users have had a reasonable opportunity to update.

Please avoid accessing data that does not belong to you, disrupting production sites, or publicly disclosing an unresolved issue.
